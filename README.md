### [Dunst](https://github.com/dunst-project/dunst)

> This is the *terminal emulator*, so it makes it look better (?  

### [NVIM](https://github.com/neovim/neovim)
> The father of all IDE's, nothing like VI v3 tho  

### Systemd (not main files)
> Some random crap I needed to backup bruh

> Kinda *status bar*, makes Arch more dynamic and shows relevant things  

### [WoFi](https://github.com/SimplyCEO/wofi)
> *App launcher*, cause launching apps via terminal is for washed ppl  

### Install.sh
> *Script* to install **ALL** the software and dotfiles
